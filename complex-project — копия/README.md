# 🏝️ Windows Dynamic Island (Полная версия: Акты 1, 2 и 3)

Нативный интерактивный оверлей **Dynamic Island** для Windows с пружинной физикой (`60 FPS Hooke's Law`), эффектом жидкого разделения (`Liquid Metaball`) и глубокой интеграцией с ОС Windows.

## 🚀 Быстрый запуск
Дважды кликните по файлу **`run.bat`** или выполните в терминале:
```powershell
python main.py
```

---

## ✨ Реализованный функционал

### 🎵 Акт 1: Базовые фичи оригинала (Apple Dynamic Island)
1. **Мультимедиа (Now Playing)**:
   - В свернутом виде: мини-обложка трека слева + анимированная волна эквалайзера справа, синхронизированная с реальным пиковым уровнем звука системы Windows (`WASAPI / Pycaw Peak Meter`).
   - По клику: пружинное раскрытие в карточку плеера (большая обложка с цветным свечением, название, исполнитель, интерактивный ползунок перемотки, `Prev`, `Play/Pause`, `Next`).
2. **Таймеры и секундомеры**:
   - Отображение обратного отсчета или секундомера прямо в плашке, круговой прогресс-ринг, пауза/старт, сброс, быстрые пресеты (`+1 мин`, `5 мин`).
3. **Батарея и питание**:
   - Автоматический мониторинг `psutil.sensors_battery()` + анимация при подключении/отключении зарядки (зеленый кружок с процентом и иконкой молнии) и индикация низкого заряда (`<20%`, `<10%`).
4. **Управление звуком и микрофоном**:
   - При изменении громкости клавишами или **колесиком мыши прямо на острове** — остров на 2 секунды расширяется и показывает горизонтальный индикатор громкости.
   - Индикатор активного микрофона (оранжевая точка конфиденциальности при захвате микрофона приложениями через реестр `CapabilityAccessManager`).
5. **Многозадачность (Двойной остров / Split Island)**:
   - Когда одновременно играет музыка (или включен HUD) и запущен таймер, остров физически делится на основную пилюлю и отдельный кружок таймера справа с жидким перешейком.

### 💻 Акт 2: Специфичные ПК-фичи (Суперсилы Windows)
1. **Умный буфер обмена (Smart Clipboard)**:
   - При `Ctrl+C` остров вспыхивает: для текста показывает превью первых слов и число символов, для картинки — миниатюру и разрешение, для цвета (`#HEX` или `rgb()`) — заливает индикатор этим цветом.
2. **Загрузки и передача файлов**:
   - Круговой индикатор прогресса загрузки файлов, скорость (`МБ/с`) и мониторинг папки `~/Downloads`.
3. **Мониторинг железа (HUD для гиков)**:
   - Компактный режим и развернутая карточка: нагрузка и температура **CPU**, загрузка **GPU**, занятая **RAM (`ГБ`)**.
4. **Корзина и Drag-and-Drop (Зона сброса)**:
   - Перетащите любой файл мышкой на остров: быстрые кнопки **Скопировать путь**, **Заархивировать в `.ZIP`**, **Временный хостинг (ссылка)** и **Переместить в Корзину Windows**.
5. **Быстрый терминал / Запуск команд (`Ctrl + Shift + Space`)**:
   - Строка быстрого ввода команд (`calc`, `notepad`, `taskmgr`, `ipconfig`), встроенный калькулятор (`256*14`) и быстрый веб-поиск (`?запрос`).
6. **Входящие уведомления**:
   - Кастомные уведомления (`Telegram`, `Discord`, `Почта`, `GitHub`) с плавным выездом из пилюли.

---

### ⚙️ Акт 3: UX-механики и настройки
1. **Smart Hide (Авто-скрытие в полноэкранных приложениях)**:
   - Автоматически определяет полноэкранные игры и фильмы (`Win32 GetForegroundWindow`) и плавно скрывает остров.
2. **Пропуск мыши (Click-through / Ghost Mode)**:
   - Включается хоткеем `Ctrl + Alt + X`, тумблером в Центре управления или **удержанием `Ctrl + Alt`**: клики проходят сквозь остров прямо во вкладки браузера под ним (`Win32 WS_EX_TRANSPARENT`).
3. **Кастомизация расположения и мониторов**:
   - Переключение между мониторами (`1, 2, 3`) и выбор позиции: **Парение с отступом**, **Прилипание к верхнему краю** или **Внизу над таскбаром**.
4. **Физика анимаций (Spring Physics)**:
   - Настоящая пружинная физика с 4 пресетами: `Упругая (Apple)`, `Быстрая (Snappy)`, `Мягкая (Gentle)`, `Желе (Extra Bounce)`.
